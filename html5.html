📘 HTML5 Master Notes

Structure & Markup Language

PART 1: FOUNDATIONS
1. Introduction to the World Wide Web
Meaning: A global network of digital documents and resources accessible via web browsers over the internet.
Definition: An information space where resources are identified by URLs, interlinked via hypertext, and retrieved using HTTP/HTTPS.
Purpose: To share, discover, store, and access cross-platform documents seamlessly worldwide.
Example: Internet is the highway system; the Web represents destinations (websites) built along those roads.
<!-- Accessing web resource via URL --> <a href="https://www.example.com">Visit Resource</a>
Task: Open DevTools (F12) in your browser and inspect the HTML structure of any popular website.
2. Client-Server Architecture
Meaning: A system where your browser (Client) requests pages, and a remote machine (Server) delivers them.
Definition: A distributed network model splitting tasks between service providers (servers) and service requesters (clients).
Purpose: To centralize data storage, manage application logic, and serve dynamic content to millions securely.
Example: Restaurant ordering—You (Client) place order, Kitchen (Server) prepares and delivers meal.
<form action="/api/submit" method="POST"> <input type="text" name="user" placeholder="Enter Name"> <button type="submit">Send Request</button> </form>
Task: Draw a request-response flowchart illustrating browser navigation to google.com.
3. HTML Document Structure
Meaning: The essential skeletal layout dividing hidden page setup from visual content.
Definition: Standard HTML tree composed of <!DOCTYPE>, <html>, <head>, and <body> elements organized hierarchically.
Purpose: Provides standardized document parsing instructions to browsers for accurate rendering.
Example: Human body—Head manages hidden logic/thoughts; Body presents visible physical traits.
<!DOCTYPE html> <html lang="en"> <head><title>Page</title></head> <body><h1>Visible Content</h1></body> </html>

PART 2: COMMENTS & METADATA
4. HTML Comments
Meaning: Hidden developer notes written inside HTML files that browsers completely ignore when rendering pages.
Definition: Non-rendered annotations enclosed between <!-- and --> tags used purely for internal documentation.
Purpose: Documents code logic, marks important sections, and temporarily disables code without deletion.
Example: Sticky notes on a desk—visible to you for reference but invisible to visitors reading the document.
<!-- This is a single-line HTML comment --> <!-- Multi-line comment: Explains why this div exists --> <div>Visible content here</div>
Task: Add 3 different comments in your HTML file: a header note, a code explanation, and a TODO note.
5. <title> Tag (Metadata)
Meaning: The element that defines the text displayed on the browser tab and in search engine results.
Definition: A required head element containing a single string shown on browser tabs, bookmarks, and SEO snippets.
Purpose: Identifies pages for users, improves SEO rankings, and provides accessibility context.
Example: The name printed on the spine of a book—helps you identify it without opening it.
<head> <title>My Portfolio - John Doe</title> </head>
Task: Create 3 HTML pages (Home, About, Contact), each with a unique descriptive title tag.
6. <meta> Tag (Metadata)
Meaning: Self-closing tags that provide hidden metadata like character encoding, viewport settings, and SEO details.
Definition: Void HTML elements inside <head> defining page-level information via 'name', 'content', 'charset', and 'property' attributes.
Purpose: Sets character encoding, enables responsive design, controls search engines, and shares social media previews.
Example: Hidden product label tags on clothing items—provides info without being part of the main design.
<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <meta name="description" content="Learn Full Stack Development"> <meta name="keywords" content="HTML, CSS, JS">
Task: Add 4 meta tags to a page: charset, viewport, description, and author.
7. <link> Tag (Metadata)
Meaning: Self-closing tag used to connect external resources like stylesheets, icons, and fonts to your HTML page.
Definition: A void element with 'rel' (relationship) and 'href' (resource path) attributes importing external files into the document.
Purpose: Loads CSS files, favicons, preloaded resources, and alternate language versions of pages.
Example: Hiring external contractors to bring in materials from outside your main project workspace.
<link rel="stylesheet" href="style.css"> <link rel="icon" href="favicon.ico" type="image/x-icon"> <link rel="preconnect" href="https://fonts.googleapis.com">
Task: Link an external CSS file and a favicon icon to your HTML page using <link> tags.
8. <style> Tag (Metadata)
Meaning: Container tag that holds internal CSS code directly inside the HTML document's head section.
Definition: Non-void HTML element wrapping CSS rules applied only to the current page's elements.
Purpose: Writes page-specific internal CSS styles without needing an external .css file.
Example: Writing paint instructions directly on a wall vs. keeping them in a separate instruction manual.
<style> body { background-color: #f4f4f9; } h1 { color: blue; text-align: center; } </style>
Task: Use a <style> tag to style your page's body background and heading colors.
9. <script> Tag (Metadata)
Meaning: Container tag used to embed executable JavaScript code inline or load external .js files.
Definition: HTML element placing executable logic into pages via inline code or 'src' attribute pointing to external scripts.
Purpose: Adds interactivity, dynamic behavior, event handling, and API communications to web pages.
Example: Adding an electric motor to a toy car—the plain body (HTML) now moves and reacts dynamically.
<!-- Inline Script --> <script> alert("Hello from JS!"); </script> <!-- External Script --> <script src="app.js" defer></script>
Task: Add an inline script that shows an alert, then link an external JS file using the 'src' attribute.
PART 3: TAGS & ATTRIBUTES
10. HTML Tags (Concept)
Meaning: Special keywords wrapped in angle brackets < > that define types of elements on your web page.
Definition: Markup instructions written as <tagname>content</tagname> (paired) or <tagname /> (self-closing) to structure documents.
Purpose: Tells the browser what kind of element to render (heading, image, link, paragraph, etc.).
Example: Labels placed on physical boxes—"Fragile", "Books", "Clothes"—so you know what's inside each box.
<!-- Paired Tag --> <p>This is a paragraph</p> <!-- Self-closing Tag --> <br /> <img src="pic.jpg" />
Task: List 10 commonly used HTML tags and classify each as paired or self-closing.
11. HTML Attributes (Concept)
Meaning: Extra properties written inside opening tags that modify the behavior or appearance of elements.
Definition: Key-value pairs following the pattern name="value" placed inside opening tags to add configuration data.
Purpose: Provides elements with IDs, classes, URLs, image paths, form data, event handlers, and more.
Example: Describing a car: Tag = "Car", Attributes = color="red", doors="4", brand="Toyota".
<!-- 'href' and 'target' are attributes --> <a href="https://google.com" target="_blank">Visit</a> <!-- 'src', 'alt', 'width' are attributes --> <img src="pic.jpg" alt="Photo" width="300">
Task: Create an anchor tag with href, target, and title attributes, plus an image with src, alt, and width.
12. Heading Tags (h1-h6)
Meaning: Six levels of heading tags used to define titles and subheadings in a hierarchical structure.
Definition: Block-level elements ranging from <h1> (largest, most important) down to <h6> (smallest, least important).
Purpose: Creates visual hierarchy, improves SEO rankings, and enhances accessibility for screen readers.
Example: Book structure—h1 is the book title, h2 is chapter names, h3 is section titles, h4+ is subsections.
<h1>Main Page Title</h1> <h2>Section Heading</h2> <h3>Sub-section</h3> <h4>Minor Heading</h4>
Task: Create a blog post structure using all 6 heading levels appropriately.
13. Paragraph Tag (<p>)
Meaning: A block-level element that wraps blocks of body text into readable paragraphs.
Definition: Paired HTML element <p>...</p> automatically adding vertical margins between text blocks.
Purpose: Organizes long-form content into readable, well-spaced paragraphs for better user experience.
Example: Writing in a notebook—each new idea starts on a fresh line with space from the previous one.
<p>This is the first paragraph of my article.</p> <p>This is a second, separate paragraph.</p>
Task: Write a short "About Me" page using 3 paragraph tags describing yourself.
14. Label Tag (<label>)
Meaning: Tag used to provide descriptive text labels for form input fields, improving accessibility.
Definition: Form-related inline element connected to inputs via the 'for' attribute matching the input's 'id'.
Purpose: Improves usability (clicking the label focuses the input) and screen reader accessibility.
Example: Writing "Name:" next to a blank line on a paper form—telling users what to fill in.
<label for="email">Email Address:</label> <input type="email" id="email" name="email">
Task: Create a form with 3 inputs (name, email, phone), each with its own associated label tag.
15. Building Your First Page "Hello World"
Meaning: The traditional first program created to confirm your file setup produces visible output.
Definition: A minimal HTML document displaying "Hello World" to verify environment configuration and syntax correctness.
Purpose: Verifies text editor, file extensions, and browser rendering are working correctly.
Example: Testing a new lamp by plugging it in to see if the light turns on properly.
<!DOCTYPE html> <html> <head><title>First Page</title></head> <body> <h1>Hello World!</h1> </body> </html>
Task: Create hello.html on your desktop and open it directly in a web browser.
16. Text Formatting Tags
Meaning: Inline tags used around text to add visual emphasis, highlights, or special formatting.
Definition: HTML inline elements including <b>, <strong>, <i>, <em>, <u>, <mark>, <sub>, <sup>, <small>, <del>.
Purpose: Improves readability, stresses key terms, and displays mathematical or scientific symbols correctly.
Example: Using fluorescent highlighter marker and underlines on a printed textbook to emphasize important words.
<p>Water formula: H<sub>2</sub>O</p> <p>Einstein: E = mc<sup>2</sup></p> <p><strong>Note:</strong> <mark>Important!</mark></p> <p><del>Old price</del> <b>New price</b></p>
Task: Write a paragraph using subscript, superscript, highlighted, bold, and strikethrough text.
17. <div> Element (Block)
Meaning: A generic, non-semantic container block used to group related elements together for styling.
Definition: Block-level element without inherent meaning used purely as a layout wrapper or styling container.
Purpose: Groups elements into sections for layout, applies CSS styles, and creates reusable layout blocks.
Example: Cardboard moving boxes—holds many related items together inside one convenient container.
<div class="card"> <h2>Product Name</h2> <p>Product description here.</p> <button>Buy Now</button> </div>
Task: Create 3 div containers (header, main, footer) and style them with different background colors.
18. <nav> Element (Block)
Meaning: A semantic block element specifically designed to hold the main navigation menu of a website.
Definition: HTML5 semantic element wrapping primary navigation links—used by browsers and screen readers to identify menus.
Purpose: Improves accessibility, SEO, and semantic clarity by explicitly marking navigation sections.
Example: A table of contents in a book—a dedicated area directing readers to different chapters.
<nav> <a href="/home">Home</a> <a href="/about">About</a> <a href="/contact">Contact</a> </nav>
Task: Build a navigation bar containing 5 menu links wrapped inside a <nav> element.
19. Image Tag (<img>)
Meaning: A self-closing tag that embeds visual graphics (photos, icons, illustrations) onto web pages.
Definition: Void element requiring 'src' (image path) and 'alt' (alternative text) attributes for display and accessibility.
Purpose: Displays visual content, improves page aesthetics, and provides accessibility via alt descriptions.
Example: A picture frame hanging on a wall—shows visual content inside a defined boundary.
<img src="logo.png" alt="Company Logo" width="200" height="100">
Task: Insert 3 images into a page with proper alt text, width, and height attributes.
20. Anchor Tag (<a>)
Meaning: A paired tag used to create clickable hyperlinks that navigate between pages or jump to sections.
Definition: Inline element using 'href' (destination URL) and 'target' (open location) attributes to create hypertext links.
Purpose: Enables web navigation between pages, external sites, email, phone, and in-page anchors.
Example: A doorway in a building—click it to walk through to a different room or location.
<a href="about.html">About Page</a> <a href="https://google.com" target="_blank">Google</a> <a href="mailto:me@mail.com">Email Me</a> <a href="#section1">Jump to Section</a>
Task: Create 4 anchor tags: internal page link, external site, email link, and in-page jump link.
21. Ordered List (<ol>)
Meaning: A numbered list used when the sequence or order of items matters.
Definition: Block element wrapping <li> items displayed with automatic numbering (1, 2, 3 or A, B, C via 'type' attribute).
Purpose: Displays step-by-step instructions, rankings, or any content where order carries meaning.
Example: A recipe's cooking steps—each step must happen in the correct numbered sequence.
<ol> <li>Install Node.js</li> <li>Create project folder</li> <li>Run npm install</li> </ol>
Task: Create an ordered list showing the top 5 steps to bake a cake.
22. Unordered List (<ul>)
Meaning: A bulleted list used when the order of items does not matter.
Definition: Block element wrapping <li> items displayed with bullet points (dots, circles, squares).
Purpose: Shows collections of items where sequence is irrelevant—features, options, categories.
Example: A grocery shopping list—items can be purchased in any order you prefer.
<ul> <li>Apples</li> <li>Bread</li> <li>Milk</li> </ul>
Task: Create an unordered list of your 5 favorite hobbies.
23. Table Structure
Meaning: HTML elements used to organize structured data into rows and columns.
Definition: Composed of <table> (container), <tr> (row), <th> (header cell), <td> (data cell), <thead>, <tbody>, <tfoot>.
Purpose: Displays tabular data like schedules, pricing comparisons, and database records clearly.
Example: A school timetable—rows for time slots, columns for days of the week.
<table border="1"> <tr><th>Name</th><th>Score</th></tr> <tr><td>Alex</td><td>90</td></tr> <tr><td>Maya</td><td>85</td></tr> </table>
Task: Build a 4-column table showing student names, subjects, grades, and attendance.
24. HTML5 Forms
Meaning: Interactive panels that collect user input and send it to a server for processing.
Definition: The <form> container wrapping input fields with 'action' (destination URL) and 'method' (GET/POST) attributes.
Purpose: Enables user registration, login, search queries, feedback, and data submission.
Example: Filling out a paper application form at a bank and submitting it at the counter.
<form action="/submit" method="POST"> <label for="user">Name:</label> <input type="text" id="user" name="username"> <button type="submit">Submit</button> </form>
Task: Build a signup form with name, email, password fields and a submit button.
25. Form Methods: GET vs POST
Meaning: Two primary HTTP methods used by forms to send user data to a server.
Definition: GET sends data in URL (visible, cached, limited size); POST sends data in request body (hidden, secure, larger).
Purpose: GET for search/retrieval; POST for sensitive data like passwords, uploads, and record creation.
Example: GET = sending a postcard (open, visible); POST = sending a sealed envelope (private, hidden).
<!-- GET: data visible in URL --> <form action="/search" method="GET">...</form> <!-- POST: data hidden in body --> <form action="/login" method="POST">...</form>
Task: Create 2 forms—a search form using GET and a login form using POST.
PART 4: HTML SELECTORS
26. Tag Selector
Meaning: Targeting an element in CSS or JavaScript using its tag name directly.
Definition: Selector matching every occurrence of a specific tag type across the entire document.
Purpose: Applies universal styles to all elements of a specific type (all h1s, all p's, all a's).
Example: Giving every student in a school the same uniform—no exceptions, affects everyone.
<!-- HTML --> <h1>Title</h1> <p>Paragraph</p> <!-- CSS: targets ALL h1s --> <style> h1 { color: red; } </style>
Task: Use a tag selector to change the color of all paragraphs on your page.
27. ID Selector
Meaning: A unique identifier assigned to one specific element on the page using the 'id' attribute.
Definition: Unique attribute (id="name") targeted in CSS using the '#' prefix (#name) — must be used only ONCE per page.
Purpose: Targets exactly one specific element precisely for styling or JavaScript manipulation.
Example: Your passport number—completely unique to you, no other person shares the same ID.
<!-- HTML --> <div id="main-header">Welcome</div> <!-- CSS: # prefix --> <style> #main-header { font-size: 40px; } </style>
Task: Create one div with a unique ID and style it specifically using the # selector.
28. Class Selector
Meaning: A reusable identifier that can be shared among multiple elements for grouped styling.
Definition: Reusable attribute (class="name") targeted in CSS using the '.' prefix (.name) — can be used multiple times.
Purpose: Groups multiple elements under one style rule, enabling consistent and reusable design.
Example: A school uniform shared by all students of the same class—same style, many wearers.
<!-- HTML: same class on multiple elements --> <div class="card">Card 1</div> <div class="card">Card 2</div> <!-- CSS: . prefix --> <style> .card { padding: 20px; } </style>
Task: Create 4 divs sharing the same class and style them all together with one rule.
PART 5: SEMANTIC & MEDIA
29. Iframes (<iframe>)
Meaning: An inline frame tag that embeds another webpage inside your current webpage.
Definition: HTML element loading external web content from a URL via 'src' attribute within a defined rectangular area.
Purpose: Embeds YouTube videos, Google Maps, external forms, or third-party content directly inside your page.
Example: A small TV screen placed inside your room showing a different channel/program.
<iframe src="https://www.youtube.com/embed/VIDEO_ID" width="560" height="315" frameborder="0" allowfullscreen> </iframe>
Task: Embed a YouTube video and a Google Map inside your page using iframes.
30. HTML Entities
Meaning: Special character codes used to display reserved HTML characters as plain text in the browser.
Definition: Character references starting with '&' and ending with ';' (e.g., &lt;, &gt;, &amp;, &nbsp;).
Purpose: Prevents browser from interpreting characters as HTML code (e.g., displaying < without starting a tag).
Example: Using escape codes in a text message to display emoji faces that your keyboard can't type directly.
<p>If 5 &lt; 10 &amp; 20 &gt; 15</p> <!-- Displays: If 5 < 10 & 20 > 15 --> <p>Space&nbsp;&nbsp;&nbsp;here</p>
Task: Use HTML entities to display: less-than, greater-than, ampersand, and non-breaking space characters.
31. HTML Symbols
Meaning: Special decorative characters like copyright, trademark, currency, and math symbols displayed via entities.
Definition: Named or numeric entity references (&copy;, &reg;, &trade;, &euro;) rendering non-keyboard symbols.
Purpose: Displays legal symbols, mathematical operators, currency marks, and arrows without needing images.
Example: Rubber stamp impressions—quick ways to add official symbols without drawing them manually.
<p>&copy; 2026 All Rights Reserved</p> <p>Brand&trade; and Reg&reg;</p> <p>Price: &euro;50 or &pound;45</p> <p>&hearts; &star; &check;</p>
Task: Build a footer using copyright (&copy;), trademark (&trade;), and heart (&hearts;) symbols.
32. Audio Tag (<audio>)
Meaning: HTML5 tag used to embed audio files like music, podcasts, or sound effects into web pages.
Definition: Paired element supporting formats like MP3, OGG, WAV with 'controls', 'autoplay', 'loop' attributes.
Purpose: Plays sound content natively in the browser without third-party plugins or players.
Example: Built-in music player speakers in your car—audio plays directly without external devices.
<audio controls> <source src="song.mp3" type="audio/mpeg"> <source src="song.ogg" type="audio/ogg"> Your browser doesn't support audio. </audio>
Task: Embed an audio file into your page with playback controls and multiple format sources.
33. Video Tag (<video>)
Meaning: HTML5 tag used to embed video files like movies, clips, or tutorials into web pages.
Definition: Paired element supporting MP4, WebM, OGG formats with 'controls', 'width', 'height', 'poster', 'autoplay' attributes.
Purpose: Streams video content natively without external players, with full control over playback behavior.
Example: A built-in TV screen mounted on your wall—plays videos directly, no DVD player needed.
<video width="640" height="360" controls poster="thumbnail.jpg"> <source src="movie.mp4" type="video/mp4"> <source src="movie.webm" type="video/webm"> </video>
Task: Embed a video file with controls, custom width/height, and a poster thumbnail image.
