Logic, Interactivity & Dynamic Behavior

PART 1: INTRODUCTION TO JS
1. History of JavaScript
Meaning: JavaScript is a programming language created to make web pages interactive.
Definition: Created by Brendan Eich at Netscape in 1995, originally named Mocha, then LiveScript, finally renamed JavaScript.
Purpose: Was built to add behavior (clicks, forms, animations) to static HTML pages inside browsers.
Example: Think of HTML as a car body, CSS as the paint, and JavaScript as the engine that makes it run.
// First JavaScript ever ran in Netscape Navigator (1995) console.log("Hello, I am JavaScript!");
Task: Research online when ECMAScript 6 (ES6) was released and list 3 features it introduced.
2. Features of JavaScript
Meaning: JavaScript has special qualities that make it powerful and widely used.
Definition: Features include being lightweight, interpreted, dynamic, cross-platform, object-based, and event-driven.
Purpose: These features allow JavaScript to run on browsers, servers (Node.js), mobile apps, and games.
Example: Like a Swiss Army knife — one tool that works in many different situations.
// JavaScript runs on browser AND server console.log("Running JS"); // Dynamic typing (no need to declare types) let x = 10; x = "Now I am a string";

3. How to Include JavaScript
Meaning: JavaScript can be added to a webpage in three different ways.
Definition: Inline (inside HTML attributes), Internal (inside <script> tags), and External (linked .js files).
Purpose: Allows developers to choose between quick inline code or clean reusable external files.
Example: Inline = writing on a sticky note, Internal = inside the book, External = separate instruction manual.
<!-- Inline --> <button onclick="alert('Hi!')">Click</button> <!-- Internal --> <script> console.log("Internal JS"); </script> <!-- External --> <script src="app.js"></script>

PART 2: DATA TYPES
4. String Data Type
Meaning: A string stores text data such as names, messages, or paragraphs.
Definition: A sequence of characters wrapped in single quotes ' ', double quotes " ", or backticks ` `.
Purpose: Stores and manages all text-based information in a program.
Example: Like writing a word on a piece of paper and labeling it.
let name = "Alex"; let greeting = 'Hello World'; let message = `Hi, ${name}!`; // template literal
Task: Create 3 string variables using single, double, and backtick quotes.
5. Number Data Type
Meaning: A number stores numeric values like age, price, or scores.
Definition: JavaScript has only one number type that handles both integers and decimals (floats).
Purpose: Used for calculations, counting, pricing, and mathematical operations.
Example: Like writing down an exam score or price tag.
let age = 25; let price = 199.99; let negative = -50;
Task: Create 3 number variables for your age, height, and bank balance.
6. Boolean Data Type
Meaning: A boolean stores only one of two values: true or false.
Definition: A binary data type representing yes/no, on/off, or 1/0 states.
Purpose: Used for logic decisions, conditions, flags, and comparisons.
Example: Light switch — ON (true) or OFF (false).
let isLoggedIn = true; let isAdmin = false;
Task: Create boolean variables for isStudent, isMarried, and hasLicense.
7. Undefined Data Type
Meaning: Undefined means a variable was declared but no value was assigned.
Definition: The default value given automatically by JavaScript when a variable has no assigned value.
Purpose: Shows that a variable exists but is still empty.
Example: Like an empty cup — the cup exists, but nothing is inside.
let user; console.log(user); // undefined

8. Null Data Type
Meaning: Null represents an intentional "empty" or "no value" state.
Definition: A special value that developers assign deliberately to show something is empty.
Purpose: Used to intentionally clear or reset a variable.
Example: A clean whiteboard — intentionally wiped empty.
let selectedUser = null; console.log(selectedUser); // null

9. Object Data Type
Meaning: An object stores multiple related values together as key-value pairs.
Definition: A collection of properties enclosed in curly braces { } with key:value structure.
Purpose: Groups related data (like a student's name, age, and grade) in a single container.
Example: Like a person's ID card holding name, DOB, and address together.
let student = { name: "Alex", age: 20, grade: "A" };

10. Array Data Type
Meaning: An array stores a list of values in a single variable.
Definition: An ordered collection of items enclosed in square brackets [ ], accessed by index starting at 0.
Purpose: Stores multiple items like a list of fruits, prices, or names.
Example: A grocery shopping list written on paper.
let fruits = ["Apple", "Banana", "Mango"]; console.log(fruits[0]); // Apple

PART 3: VARIABLES & SCOPES
11. var Keyword
Meaning: The oldest way to declare variables in JavaScript.
Definition: A function-scoped variable declaration that can be re-declared and updated.
Purpose: Was the standard before 2015 for creating variables throughout a function.
Example: Like a public message board — anyone in the function can read or change it.
var name = "Alex"; var name = "Bob"; // allowed console.log(name); // Bob
Task: Create a var variable, re-declare it, and print both values.
12. let Keyword
Meaning: A modern way to declare variables whose values can change.
Definition: A block-scoped variable declaration (works only inside { } where defined) introduced in ES6.
Purpose: Used for variables that need to be updated later but kept within a specific scope.
Example: Like a classroom note — only valid inside that classroom (block).
let count = 0; count = 10; // allowed // let count = 5; // ERROR: cannot re-declare
Task: Create a let variable "score", change its value 3 times, and print each change.
13. const Keyword
Meaning: Used to declare variables whose values must never change.
Definition: A block-scoped variable declaration that cannot be reassigned after initialization.
Purpose: Used for constants, configuration values, and fixed data.
Example: Like a birth date — once set, it never changes.
const PI = 3.14159; // PI = 3.14; // ERROR: cannot reassign const
Task: Create a const variable "COUNTRY" and try to change it to see the error.
14. Global Scope
Meaning: Variables accessible everywhere in the code.
Definition: Variables declared outside any function or block, available in the entire program.
Purpose: Shares data across multiple functions and files.
Example: A public announcement heard by everyone in a building.
let appName = "MyApp"; // global function show() { console.log(appName); // accessible }
Task: Create a global variable and access it inside 2 different functions.
15. Local / Block Scope
Meaning: Variables accessible only inside a specific function or block.
Definition: Variables declared inside { } or a function, invisible outside that scope.
Purpose: Keeps variables private and prevents accidental changes from outside.
Example: A whisper between two people — nobody else can hear it.
function greet() { let msg = "Hello"; console.log(msg); // works } // console.log(msg); // ERROR
Task: Create a function with a local variable and try accessing it outside the function.
PART 4: OPERATORS
16. Arithmetic Operators
Meaning: Operators that perform math calculations on numbers.
Definition: Include + (add), - (subtract), * (multiply), / (divide), % (remainder), ** (power).
Purpose: Used for all math operations like totals, discounts, and averages.
Example: A calculator doing basic arithmetic.
let a = 10, b = 3; console.log(a + b); // 13 console.log(a % b); // 1 (remainder) console.log(a ** 2); // 100 (power)
Task: Calculate 25 + 4, 25 - 4, 25 * 4, 25 / 4, and 25 % 4.
17. Assignment Operators
Meaning: Operators used to assign or update values in a variable.
Definition: Include = (assign), +=, -=, *=, /=, %= (compound assignment operators).
Purpose: Writes less code when updating variable values.
Example: Adding money to a bank account instead of calculating total each time.
let x = 10; x += 5; // x = x + 5 = 15 x -= 2; // x = 13 x *= 2; // x = 26
Task: Start with a variable at 100 and use += 20, -= 10, *= 3 to update it.
18. Comparison Operators
Meaning: Operators that compare two values and return true or false.
Definition: Include == (equal), === (strict equal), != , !==, >, <, >=, <=.
Purpose: Used in conditions, loops, and validation checks.
Example: A judge comparing two scores to decide a winner.
console.log(10 == "10"); // true (loose) console.log(10 === "10"); // false (strict) console.log(5 > 3); // true
Task: Compare 5 == "5" and 5 === "5" and explain the difference.
19. Logical Operators
Meaning: Operators that combine multiple boolean conditions.
Definition: Include && (AND), || (OR), ! (NOT).
Purpose: Used in complex decision-making like login validation.
Example: "You can enter only IF you have a ticket AND an ID."
let age = 20, hasID = true; console.log(age >= 18 && hasID); // true console.log(age < 18 || hasID); // true console.log(!hasID); // false
Task: Write a logic check: user can log in if (age >= 18 AND hasPassword).
PART 5: CONDITIONAL STATEMENTS
20. if Statement
Meaning: Executes a block of code only if a condition is true.
Definition: The simplest conditional statement using the keyword "if" followed by a condition in parentheses.
Purpose: Allows programs to make yes/no decisions.
Example: "If it's raining, take an umbrella."
let age = 20; if (age >= 18) { console.log("Adult"); }
Task: Write an if statement checking if a number is positive.
21. if-else Statement
Meaning: Executes one block if the condition is true, another block if false.
Definition: An extension of the if statement with an "else" clause for alternative action.
Purpose: Handles two different outcomes based on a condition.
Example: "If pass, celebrate; else, study harder."
let score = 45; if (score >= 50) { console.log("Pass"); } else { console.log("Fail"); }
Task: Write an if-else that checks if a number is even or odd.
22. else if Statement
Meaning: Checks multiple conditions one after another.
Definition: A chain of conditions evaluated in order until one is true.
Purpose: Handles more than two possible outcomes.
Example: Giving grades: A, B, C, D, or F based on marks.
let marks = 75; if (marks >= 90) console.log("A"); else if (marks >= 75) console.log("B"); else if (marks >= 60) console.log("C"); else console.log("F");
Task: Write a program that gives grades (A/B/C/D/F) based on marks.
23. switch Statement
Meaning: A cleaner way to check multiple exact values of one variable.
Definition: A conditional that uses "case" blocks to match exact values and a "default" fallback.
Purpose: Used when checking one variable against many fixed values.
Example: A vending machine giving different items based on button pressed.
let day = "Monday"; switch (day) { case "Monday": console.log("Start week"); break; case "Friday": console.log("Almost weekend"); break; default: console.log("Normal day"); }
Task: Write a switch for days of the week that prints a mood message for each.
PART 6: FUNCTIONS
24. Built-in Functions
Meaning: Pre-defined functions that come built into JavaScript.
Definition: Functions provided by the language such as alert(), prompt(), parseInt(), isNaN(), Math.max().
Purpose: Perform common tasks without writing code from scratch.
Example: Pre-installed apps on your phone — ready to use immediately.
alert("Hello!"); let num = parseInt("25"); let max = Math.max(10, 20, 5);

25. Regular (User-defined) Functions
Meaning: Functions created by the programmer for custom tasks.
Definition: Declared using the "function" keyword followed by name, parameters, and a code block.
Purpose: Allows reusing the same code multiple times.
Example: A recipe you wrote yourself and can use anytime you cook.
function greet() { console.log("Hello!"); } greet();

26. Function Parameters
Meaning: Variables passed into a function to use its logic with different inputs.
Definition: Values listed inside parentheses when defining a function, acting as placeholders for arguments.
Purpose: Makes functions flexible and reusable with different data.
Example: A coffee machine where you choose the type and size as input.
function greet(name) { console.log("Hello, " + name); } greet("Alex"); greet("Maya");

27. Return Values
Meaning: A function can send back a result using the "return" keyword.
Definition: The "return" statement sends a value from a function back to the code that called it.
Purpose: Allows functions to produce usable output for further operations.
Example: A vending machine giving you a drink after you insert money.
function add(a, b) { return a + b; } let total = add(5, 10); // 15

28. Creating Arrays
Meaning: Arrays are lists that hold multiple values in order.
Definition: Collections created with [ ] or the Array() constructor, where each item has an index starting at 0.
Purpose: Stores grouped data like a list of users, prices, or items.
Example: A train with multiple numbered coaches.

29. push() Method
Meaning: Adds a new item to the end of an array.
Definition: An array method that modifies the original array by appending items.
Purpose: Grows an array dynamically with new data.
Example: Adding a new book to the end of a bookshelf.
let fruits = ["Apple", "Banana"]; fruits.push("Mango"); // ["Apple", "Banana", "Mango"]

Meaning: Removes the last item from an array.
Definition: An array method that removes and returns the final element.
Purpose: Shrinks an array by removing the latest entry.
Example: Removing the last book you placed on a shelf.
let fruits = ["Apple", "Banana", "Mango"]; fruits.pop(); // removes "Mango"

31. String length Property
Meaning: Returns the total number of characters in a string.
Definition: A built-in property of strings that counts all characters including spaces.
Purpose: Used to validate inputs, truncate text, or check text size.
Example: Counting letters in a word to check if a password is long enough.
let name = "JavaScript"; console.log(name.length); // 10

32. toUpperCase() and toLowerCase()
Meaning: Methods that change string case to all capital or all lowercase letters.
Definition: Built-in string methods that return a new string with converted case.
Purpose: Used for standardizing user input and formatting text display.
Example: Shouting a word (uppercase) vs whispering it (lowercase).
let name = "javascript"; console.log(name.toUpperCase()); // JAVASCRIPT console.log(name.toLowerCase()); // javascript

Definition: A method using (start, end) indexes to copy a specific portion into a new string or array.
Purpose: Used to get substrings, previews, usernames, or specific list items.
Example: Cutting a specific slice of pizza without touching the rest.
let text = "JavaScript"; console.log(text.slice(0, 4)); // Java

PART 9: DOCUMENT OBJECT MODEL (DOM)
40. DOM Structure
Meaning: The DOM represents an HTML page as a tree of objects that JavaScript can modify.
Definition: Document Object Model is a programming interface that treats every HTML tag as a node in a tree structure.
Purpose: Allows JavaScript to read, change, add, and delete page elements dynamically.
Example: Like a family tree where parent and child elements have clear relationships.
// HTML page becomes a tree: // document // └── html // ├── head // └── body // └── h1, p, div, etc.
Task: Draw a DOM tree diagram of a simple HTML page with 1 head and 1 body.
41. DOM Hierarchy
Meaning: The parent-child relationships between HTML elements.
Definition: Each HTML element is a node with parentNode, childNodes, firstChild, lastChild, and siblings.
Purpose: Helps navigate and traverse the DOM programmatically.
Example: A div (parent) containing paragraphs (children).
let box = document.getElementById("box"); console.log(box.parentNode); console.log(box.children);
Task: Create a div with 3 paragraphs and print its children in the console.
42. getElementById()
Meaning: Selects one HTML element using its unique ID.
Definition: A DOM method that returns the element with the matching id attribute.
Purpose: Targets a specific element to read or change its content/style.
Example: Calling a specific person by their unique ID number.
let title = document.getElementById("main-title"); title.innerText = "New Title!";
Task: Create an h1 with id="title" and change its text using getElementById.
43. getElementsByClassName()
Meaning: Selects all HTML elements that share the same class name.
Definition: A DOM method that returns a live HTMLCollection of matching elements.
Purpose: Modifies multiple similar elements at once.
Example: Grouping all students wearing the same uniform.
let cards = document.getElementsByClassName("card"); console.log(cards.length);
Task: Create 3 divs with class="box" and count them using this method.
44. querySelector()
Meaning: Selects the first HTML element matching any CSS selector.
Definition: A modern DOM method using CSS selector syntax (#id, .class, tag).
Purpose: Provides flexible and powerful element selection.
Example: Picking the first red apple from a basket.
let btn = document.querySelector(".btn"); let header = document.querySelector("#header"); let firstP = document.querySelector("p");
Task: Use querySelector to select the first h2 and change its color.
45. DOM Manipulation
Meaning: Changing HTML content, structure, or style using JavaScript.
Definition: Uses properties/methods like innerText, innerHTML, style, setAttribute, appendChild, removeChild.
Purpose: Creates dynamic, interactive user interfaces.
Example: Live editing text on a webpage without reloading.
let box = document.getElementById("box"); box.innerText = "New Content"; box.style.color = "red"; box.setAttribute("class", "new-class");

PART 10: EVENT HANDLING
46. Click Event
Meaning: An action that happens when a user clicks an element.
Definition: A DOM event triggered on mouse click, handled using addEventListener("click", function).
Purpose: Allows users to interact with buttons, links, cards, and images.
Example: Pressing a doorbell to make it ring.
let btn = document.getElementById("myBtn"); btn.addEventListener("click", function() { alert("Button Clicked!"); });
Task: Create a button that shows "Hello!" alert on click.
47. Submit Event
Meaning: An event triggered when a form is submitted.
Definition: A DOM event fired on form submission, used with addEventListener("submit", callback).
Purpose: Validates form data before sending it to the server.
Example: A security guard checking IDs before letting people enter.
let form = document.getElementById("myForm"); form.addEventListener("submit", function(e) { e.preventDefault(); // stop page reload alert("Form submitted!"); });
Task: Create a form with name input, prevent reload, and alert the name.
48. Keypress Event
Meaning: An event triggered when a user presses a keyboard key.
Definition: A DOM event using addEventListener("keydown", "keyup", or "keypress") with event.key info.
Purpose: Builds search bars, shortcuts, and real-time typing effects.
Example: A typewriter printing a letter each time a key is pressed.
let input = document.getElementById("search"); input.addEventListener("keydown", function(e) { console.log("You pressed: " + e.key); });
Task: Create an input field and print each key pressed in the console.
