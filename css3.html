🎨 CSS3 Master Notes

Cascading Style Sheets — Styling, Layout & Responsive Design

PART 1: CSS FOUNDATIONS
1. Introduction to CSS
Meaning: CSS is used to make HTML pages beautiful by adding colors, spacing, fonts, layouts, and animations.
Definition: CSS stands for Cascading Style Sheets. It is a styling language used to control the visual appearance of HTML elements.
Purpose: It separates webpage content (HTML) from webpage design (CSS).
Example: HTML is the structure of a house; CSS is the paint, furniture, colors, and decoration.
body { background-color: lightblue; color: navy; }
Task: Change your webpage background to light yellow and paragraph text to dark blue.
2. CSS Syntax
Meaning: CSS syntax is the writing format used to create styling rules.
Definition: A CSS rule contains a selector and a declaration block. Declarations contain a property and a value.
Purpose: It tells the browser which element to style and how to style it.
Example: Selector = person’s name; property = what you want to change; value = the new setting.
p { color: red; font-size: 20px; }
Task: Write a CSS rule that makes all h1 headings green and 32px.
3. Inline CSS
Meaning: Inline CSS is CSS written directly inside an HTML element.
Definition: It uses the style attribute inside an opening HTML tag.
Purpose: It is useful for quick styling of one particular element.
Example: Like painting only one chair in a room.
<h1 style="color: red; font-size: 35px;"> Hello World </h1>
Task: Create one paragraph with inline CSS that gives it purple text.
4. Internal CSS
Meaning: Internal CSS is written inside a style tag within one HTML file.
Definition: It is CSS placed between <style> and </style> inside the HTML head section.
Purpose: It styles one complete page without creating a separate CSS file.
Example: Like keeping decoration instructions inside one room only.
<head> <style> h1 { color: blue; } </style> </head>
Task: Use internal CSS to style all paragraph tags with a gray color.
5. External CSS
Meaning: External CSS is written in a separate file ending with .css.
Definition: A CSS file is connected to HTML using the link tag.
Purpose: It keeps code clean and lets many HTML pages share the same design.
Example: Like keeping one common rulebook used by every classroom in a school.
<!-- index.html --> <link rel="stylesheet" href="style.css"> /* style.css */ h1 { color: teal; }
Task: Create style.css and link it with an HTML file.
PART 2: CSS SELECTORS
6. Tag Selector
Meaning: A tag selector chooses elements using their HTML tag name.
Definition: It targets every occurrence of a tag, such as p, h1, button, or div.
Purpose: It applies the same style to all elements of one type.
Example: Giving every paragraph on a page the same text color.
p { color: navy; }
Task: Use a tag selector to make every h2 heading orange.
7. ID Selector
Meaning: An ID selector styles one unique element.
Definition: It uses an HTML id attribute and a # symbol in CSS.
Purpose: It targets one specific element precisely.
Example: A passport number is unique to one person.
<h1 id="main-title">My Website</h1> #main-title { color: crimson; }
Task: Create a div with id="banner" and style its background color.
8. Class Selector
Meaning: A class selector styles multiple elements that share the same class name.
Definition: It uses the class attribute in HTML and a dot (.) in CSS.
Purpose: It creates reusable styles for cards, buttons, alerts, and sections.
Example: Students wearing the same uniform belong to the same group.
<div class="card">Card One</div> <div class="card">Card Two</div> .card { border: 2px solid blue; padding: 15px; }
Task: Create three cards with the same class and style them together.
9. Descendant Combinator
Meaning: It selects elements placed anywhere inside another element.
Definition: It uses a space between two selectors.
Purpose: It styles child elements inside a particular parent section.
Example: Style only paragraphs that are inside an article.
article p { color: green; }
Task: Create a div with paragraphs inside it and color only those paragraphs blue.
10. Child Combinator
Meaning: It selects only direct children of an element.
Definition: It uses the greater-than symbol (>) between selectors.
Purpose: It gives more exact control than a descendant selector.
Example: Select only children, not grandchildren.
div > p { font-weight: bold; }
Task: Style only direct p children of a div using the > combinator.
11. Adjacent Sibling Combinator
Meaning: It selects the element immediately after another element.
Definition: It uses the plus (+) symbol between selectors.
Purpose: It styles the next element only when it comes directly after another one.
Example: Style the paragraph directly after an h2 heading.
h2 + p { color: purple; }
Task: Create an h2 followed by a paragraph and style that paragraph.
12. General Sibling Combinator
Meaning: It selects all sibling elements that appear after another element.
Definition: It uses the tilde (~) symbol between selectors.
Purpose: It styles multiple related sibling elements.
Example: Style every paragraph after a heading in the same container.
h2 ~ p { color: brown; }
Task: Create one h2 and three paragraphs after it. Style all three paragraphs.
PART 3: PSEUDO CLASSES & ELEMENTS
13. Pseudo-class
Meaning: A pseudo-class styles an element in a special state.
Definition: It uses a single colon (:) followed by a state name such as hover, focus, active, or first-child.
Purpose: It makes webpages interactive without JavaScript.
Example: A button changing color when the mouse moves over it.
button:hover { background-color: red; color: white; }
Task: Create a button that turns green when you hover over it.
14. :hover Pseudo-class
Meaning: It styles an element when the mouse pointer is over it.
Definition: A CSS state selector written as :hover.
Purpose: It gives visual feedback that an element is clickable or interactive.
Example: A shop button becoming darker when a customer points at it.
a:hover { color: red; text-decoration: underline; }
Task: Make a link turn red and underlined on hover.
15. :focus Pseudo-class
Meaning: It styles an input when the user clicks it or selects it with a keyboard.
Definition: A CSS pseudo-class written as :focus.
Purpose: It helps users see which form field is currently active.
Example: A glowing border around an input box while typing.
input:focus { outline: 3px solid skyblue; border-color: blue; }
Task: Add a blue outline to an input field when it receives focus.
16. Pseudo-element
Meaning: A pseudo-element styles a particular part of an element.
Definition: It uses double colons (::), such as ::before, ::after, and ::first-letter.
Purpose: It adds decoration or changes a small part of content without adding extra HTML.
Example: Making only the first letter of a paragraph large.
p::first-letter { font-size: 40px; color: crimson; }
Task: Make the first letter of every paragraph larger using ::first-letter.
17. ::before and ::after
Meaning: These pseudo-elements add content before or after an element.
Definition: They create virtual content using the CSS content property.
Purpose: They add icons, labels, decorations, and effects without extra HTML tags.
Example: Adding a star before every important heading.
h2::before { content: "★ "; color: gold; } h2::after { content: " ✓"; color: green; }
Task: Add a ⭐ symbol before every h2 heading.
18. Attribute Selector
Meaning: It selects HTML elements according to their attributes.
Definition: It uses square brackets, such as [type="email"] or [required].
Purpose: It styles elements based on their type, value, or other attributes.
Example: Styling only password fields, not all input fields.
input[type="password"] { border: 2px solid red; } input[required] { background-color: #fff8cc; }
Task: Give all email input fields a green border using an attribute selector.
PART 4: TEXT, FONTS & UNITS
19. font-family
Meaning: font-family changes the typeface of text.
Definition: A CSS property that selects a preferred font and fallback fonts.
Purpose: It improves design, branding, and readability.
Example: Choosing handwriting, formal, or computer-style letters.
p { font-family: Arial, Helvetica, sans-serif; }
Task: Use Georgia font for headings and Arial font for paragraphs.
20. font-size
Meaning: font-size controls how large text appears.
Definition: A CSS property that accepts units such as px, rem, em, %, vw, and more.
Purpose: It creates a clear visual hierarchy between headings and normal text.
Example: A newspaper has large titles and smaller body text.
h1 { font-size: 40px; } p { font-size: 18px; }
Task: Set h1 to 40px and paragraph text to 18px.
21. color
Meaning: color changes the text color of an element.
Definition: A CSS property that accepts named colors, HEX, RGB, RGBA, HSL, and HSLA values.
Purpose: It improves visibility, branding, emphasis, and readability.
Example: Important warning text is often red.
h1 { color: #005f73; } .warning { color: rgb(220, 20, 60); }
Task: Style a heading using HEX color and a paragraph using RGB color.
22. font-weight
Meaning: font-weight controls how thick or bold text appears.
Definition: It accepts values such as normal, bold, lighter, bolder, or numeric values from 100 to 900.
Purpose: It highlights important headings, labels, and key information.
Example: Book titles are usually bolder than normal paragraphs.
h1 { font-weight: 700; } p { font-weight: 400; }
Task: Make your h2 heading bold and paragraph text normal.
23. font-style
Meaning: font-style changes text into normal, italic, or oblique style.
Definition: A CSS property with values such as normal, italic, and oblique.
Purpose: It gives special emphasis to quotes, notes, and titles.
Example: A quote in a book is often written in italic.
blockquote { font-style: italic; }
Task: Create a quote paragraph and make it italic.
24. text-align
Meaning: text-align controls horizontal alignment of text.
Definition: It accepts left, right, center, and justify values.
Purpose: It controls the layout and presentation of text content.
Example: A page title is often centered, while article text is left-aligned.
h1 { text-align: center; } p { text-align: justify; }
Task: Center a heading and justify a long paragraph.
25. CSS Measurement Units
Meaning: CSS units measure the size of fonts, widths, heights, margins, and padding.
Definition: Units can be absolute (px) or relative (%, em, rem, vw, vh).
Purpose: They help layouts work correctly on different screen sizes.
Example: px is like a fixed ruler; % is like using part of the available space.
.box { width: 80%; height: 200px; padding: 1rem; font-size: 1.2em; }
Task: Create a box with width 80%, height 200px, and padding 1rem.
PART 5: BOX MODEL
26. CSS Box Model
Meaning: Every HTML element is treated as a rectangular box.
Definition: The CSS box model contains content, padding, border, and margin.
Purpose: It controls element size and spacing in webpage layouts.
Example: A framed photo: photo = content, inner space = padding, frame = border, outside gap = margin.
.card { width: 250px; padding: 20px; border: 2px solid navy; margin: 25px; }
Task: Create a card and apply width, padding, border, and margin.
27. Padding
Meaning: Padding is space inside an element, between the content and border.
Definition: It can be set using padding, padding-top, padding-right, padding-bottom, and padding-left.
Purpose: It prevents text and content from touching the element border.
Example: The empty space inside a gift box around the gift.
.box { padding: 20px; }
Task: Apply 25px padding to a paragraph container.
28. Margin
Meaning: Margin is space outside an element.
Definition: It controls the gap between one element and nearby elements.
Purpose: It creates breathing room between sections and components.
Example: The empty space between two picture frames on a wall.
.box { margin: 30px; }
Task: Give two div elements 20px space between each other.
29. Border
Meaning: A border is the visible line around an element.
Definition: It uses width, style, and color values.
Purpose: It separates elements visually and makes cards, forms, and buttons clearer.
Example: The frame around a photograph.
.box { border: 3px dashed crimson; }
Task: Create one solid blue border and one dashed red border.
30. border-radius
Meaning: border-radius rounds the corners of an element.
Definition: A CSS property measured in px or percentage.
Purpose: It creates modern buttons, circular images, and rounded cards.
Example: Changing a sharp square box into a smooth rounded box.
.button { border-radius: 25px; } .profile-image { border-radius: 50%; }
Task: Create a rounded button and a circular profile image.
PART 6: ADVANCED CSS
31. box-shadow
Meaning: box-shadow creates a shadow around an element.
Definition: It uses horizontal offset, vertical offset, blur, spread, and color values.
Purpose: It gives cards, buttons, and boxes a raised 3D appearance.
Example: A physical card casting a shadow on a table.
.card { box-shadow: 5px 5px 15px rgba(0, 0, 0, 0.3); }
Task: Add a soft shadow to a product card.
32. text-shadow
Meaning: text-shadow adds a shadow behind text.
Definition: It works like box-shadow but applies only to letters.
Purpose: It makes headings more visible and decorative.
Example: Text on a signboard with a dark shadow behind it.
h1 { text-shadow: 2px 2px 4px gray; }
Task: Add a red shadow behind one heading.
33. Background Color
Meaning: background-color fills an element with a solid color.
Definition: A CSS property that accepts color values such as names, HEX, RGB, and HSL.
Purpose: It creates visual sections and improves readability.
Example: Painting the wall behind a section.
section { background-color: #e0f7fa; }
Task: Give header, main, and footer different background colors.
34. Background Image
Meaning: background-image places an image behind content.
Definition: It uses the url() function to load an image file.
Purpose: It creates hero sections, banners, wallpapers, and visual effects.
Example: Using wallpaper on a wall instead of plain paint.
.hero { background-image: url("banner.jpg"); }
Task: Add a background image to a hero section.
35. background-size and background-position
Meaning: These properties control image size and placement in the background.
Definition: background-size can use cover, contain, px, or percentage. background-position controls location.
Purpose: It makes background images fit correctly on different screens.
Example: Adjusting a photo inside a picture frame.
.hero { background-image: url("banner.jpg"); background-size: cover; background-position: center; background-repeat: no-repeat; }
Task: Create a full-screen banner using background-size: cover.
36. CSS Transition
Meaning: A transition makes style changes smooth instead of sudden.
Definition: It controls property change duration, timing function, delay, and affected property.
Purpose: It creates smooth hover effects and better user interaction.
Example: A door slowly opening rather than instantly jumping open.
button { background-color: blue; transition: background-color 0.3s ease; } button:hover { background-color: red; }
Task: Make a button smoothly change color in 0.5 seconds on hover.
37. 2D Transform
Meaning: A 2D transform moves, rotates, scales, or skews an element on a flat screen.
Definition: It uses transform functions such as translate(), rotate(), scale(), and skew().
Purpose: It creates interactive hover effects and movement.
Example: Moving or rotating a paper card on a desk.
.card:hover { transform: translateY(-10px) scale(1.05); }
Task: Make a card move 10px upward when hovered.
38. CSS Animation
Meaning: CSS animation changes an element automatically over time.
Definition: It uses @keyframes and animation properties.
Purpose: It creates loaders, moving objects, fade effects, and attention-grabbing designs.
Example: A loading circle spinning while a webpage is opening.
@keyframes moveBox { from { transform: translateX(0); } to { transform: translateX(200px); } } .box { animation: moveBox 2s infinite alternate; }
Task: Animate a small box so it moves from left to right.
39. CSS Gradient
Meaning: A gradient creates a smooth transition between two or more colors.
Definition: CSS supports linear-gradient() and radial-gradient().
Purpose: It creates colorful backgrounds without using image files.
Example: A sunset changing smoothly from orange to pink to purple.
.banner { background: linear-gradient(45deg, #ff007f, #7f00ff); }
Task: Create a button with a blue-to-purple linear gradient.
40. z-index
Meaning: z-index controls which positioned element appears in front.
Definition: A higher z-index value appears above a lower z-index value.
Purpose: It manages overlapping menus, modals, badges, and popups.
Example: Papers stacked on a desk: the top paper covers the papers under it.
.menu { position: fixed; z-index: 1000; }
Task: Create two overlapping boxes and bring one box to the front using z-index.
PART 7: RESPONSIVE DESIGN
41. Meta Viewport
Meaning: The viewport meta tag helps websites display correctly on mobile devices.
Definition: It sets the page width to the device width and controls initial zoom.
Purpose: It is required for mobile-friendly responsive websites.
Example: It tells the browser to fit the webpage to the phone screen.
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Task: Add the viewport meta tag to every HTML page you create.
42. Media Queries
Meaning: Media queries apply CSS only when certain screen conditions are true.
Definition: They use @media rules with conditions such as max-width or min-width.
Purpose: They make webpages responsive on mobile, tablet, and desktop screens.
Example: A three-column layout becoming one column on a phone.
@media (max-width: 768px) { body { background-color: black; color: white; } }
Task: Change your page background to black when the screen is below 768px.
43. Flexbox
Meaning: Flexbox is a one-dimensional layout system for arranging items in rows or columns.
Definition: It starts with display: flex and uses properties such as justify-content, align-items, flex-wrap, and gap.
Purpose: It easily aligns navigation bars, cards, buttons, and responsive layouts.
Example: Organizing books neatly on one shelf.
.container { display: flex; justify-content: space-between; align-items: center; gap: 20px; }
Task: Create three cards in one row using Flexbox.
44. CSS Grid
Meaning: CSS Grid is a two-dimensional layout system for rows and columns.
Definition: It starts with display: grid and uses grid-template-columns, grid-template-rows, and gap.
Purpose: It builds dashboards, photo galleries, product grids, and complex page layouts.
Example: A chessboard or timetable made of rows and columns.
.gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } @media (max-width: 768px) { .gallery { grid-template-columns: 1fr; } }
Task: Create a 3-column card layout that becomes 1 column on mobile.
