Structured Front-End Web Framework

PART 1: ANGULAR FOUNDATIONS
1. Introduction to Angular
Meaning: Angular is a complete development platform built by Google for creating structured single-page web applications.
Definition: A open-source client-side framework that extends HTML syntax with dynamic attributes to build interactive web applications.
Purpose: Helps developers create structured web interfaces without writing complex manual DOM manipulation code.
Example: A smart form template that automatically calculates totals as soon as a user types a quantity.
<!-- Including AngularJS via CDN library --> <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
Task: Research the key difference between original AngularJS (v1.x) and modern Angular (v2+ TypeScript).
2. Advantages of Angular
Meaning: The powerful benefits that make Angular ideal for building large, structured web applications.
Definition: Features two-way data binding, modular architecture, reusable directives, dependency injection, and integrated testing.
Purpose: Speeds up development time and keeps large team codebases organized, consistent, and easy to maintain.
Example: Using an automated assembly line where parts sync together automatically instead of manual fitting.
<!-- Two-way data binding: Input instantly updates the paragraph --> <div ng-app=""> <input type="text" ng-model="username" placeholder="Type name..."> <h2>Hello {{username}}!</h2> </div>

3. Disadvantages of Angular
Meaning: The limitations and challenges developers face when choosing Angular for a web project.
Definition: Includes a steep learning curve, heavier framework size, potential performance lag with massive DOM binding arrays, and SEO setup effort.
Purpose: Evaluates whether Angular is the right tool for a project compared to lighter libraries like React or Vue.
Example: Driving a heavy delivery truck for a quick errand when a small bicycle would be faster and easier.

Meaning: Setting up your project workspace with the required Angular libraries or command-line tools.
Definition: Done by linking the Angular script via CDN for simple setups or installing Angular CLI via Node Package Manager (NPM).
Purpose: Prepares the project workspace with tools needed to run, build, and execute Angular applications.
Example: Setting up an artist easel, paints, and brushes before beginning to paint a canvas.

PART 2: MVC ARCHITECTURE
5. MVC Architecture Overview
Meaning: A software design pattern that divides an application into three interconnected parts to separate concerns.
Definition: Stands for Model-View-Controller, separating application data (Model), screen layout (View), and logic (Controller).
Purpose: Makes code modular so developers can work on logic, design, and data independently without breaking other parts.
Example: Restaurant pattern: Kitchen holds food data (Model), Dining table is where you eat (View), Waiter carries orders (Controller).
// MVC Flow Concept: // USER interactions -> VIEW -> CONTROLLER updates -> MODEL -> updates -> VIEW
Task: Draw a block diagram showing how data flows between Model, View, and Controller in an application.
6. Model in MVC
Meaning: The data layer of the application responsible for holding raw information, business logic, and rules.
Definition: Represents application state objects and data arrays managed inside JavaScript variables or scope services.
Purpose: Stores and manages application data independently of how it looks on screen.
Example: A bank account database holding your balance numbers, account ID, and transaction history.
// Model data inside Angular scope $scope.student = { name: "Alex", grade: "A+", age: 20 };
Task: Define a Model object representing a product with name, price, and inStock attributes.
7. View in MVC
Meaning: The visual user interface (HTML/CSS) that displays Model data on screen to the user.
Definition: The HTML template containing Angular directives and expressions ({{ data }}) rendered in the browser.
Purpose: Presents information visually and accepts user inputs through buttons, forms, and input fields.
Example: A mobile phone screen displaying your contacts list visually.
<!-- The VIEW template displaying Model properties --> <div class="profile-card"> <h3>Student Name: {{ student.name }}</h3> <p>Grade: {{ student.grade }}</p> </div>
Task: Construct an HTML View section that displays product details using double curly brace expressions.
8. Controller in MVC
Meaning: The bridge component containing JavaScript logic that coordinates between the Model data and the View screen.
Definition: A JavaScript function controlling scope data, responding to user actions, and managing business operations.
Purpose: Listens to View user inputs, processes logic, updates Model state, and refreshes the display.
Example: A remote control translating button presses into signal actions sent to the TV screen.
app.controller('myCtrl', function($scope) { // Controller initializes Model and logic functions $scope.count = 0; $scope.increment = function() { $scope.count++; }; });

PART 3: APPLICATION CREATION & EXECUTION
9. Creating an Angular Application
Meaning: Defining an application module that initializes Angular and binds together components, controllers, and views.
Definition: Uses angular.module('appName', []) to create the root application container module.
Purpose: Acts as the central container that registers controllers, services, filters, and custom directives.
Example: Setting up a main company folder before creating individual project sub-files inside it.
<!-- HTML --> <div ng-app="myApp" ng-controller="mainCtrl"> <h1>{{ message }}</h1> </div> <!-- JS --> <script> var app = angular.module('myApp', []); // Define module app.controller('mainCtrl', function($scope) { $scope.message = "Hello Angular World!"; }); </script>
Task: Register a new Angular module called "storeApp" and attach a controller to it.
10. Executing & Running an Angular Application
Meaning: How the browser parses, bootstraps, and executes Angular code inside a web page.
Definition: Angular waits for DOM load, scans for ng-app, compiles templates, creates root scope, and starts data binding loops.
Purpose: Bootstraps static HTML markup into an active, interactive dynamic application.
Example: Turning on a car engine — the dashboard indicators light up and systems become active.
<!DOCTYPE html> <html> <head> <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script> </head> <!-- ng-app automatically bootstraps Angular on load --> <body ng-app=""> <p>Result: {{ 10 + 20 }}</p> </body> </html>

PART 4: ANGULAR DIRECTIVES
11. Introduction to Directives
Meaning: Special attributes added to HTML tags that extend HTML capabilities with dynamic features.
Definition: Markers on DOM elements (such as ng-app, ng-model, ng-repeat) telling Angular to attach custom behavior.
Purpose: Extends standard HTML into a dynamic template language for web applications.
Example: Adding turbo booster buttons to a standard bicycle to give it motorized capabilities.
<!-- Custom attributes starting with ng- are Angular directives --> <div ng-app="" ng-init="price=10"> <p>Price: {{ price }}</p> </div>
Task: Explain in your own words what an Angular directive does when placed inside an HTML tag.
12. ng-app Directive
Meaning: The root directive that defines and initializes an Angular application inside an HTML element.
Definition: A marker tag attribute that marks the root element of an Angular application, triggering auto-bootstrap.
Purpose: Tells Angular which part of the HTML page it owns and manages.
Example: Fencing off a specific plot of land to designate where building construction will take place.
<!-- Tells Angular to manage everything inside this body tag --> <body ng-app="myApp"> <div ng-controller="myCtrl"> <h1>{{ title }}</h1> </div> </body>
Task: Place `ng-app` on a wrapper div element and verify Angular directives run only inside that div.
13. ng-init Directive
Meaning: A directive used to evaluate expressions and initialize data variables directly inside HTML markup.
Definition: An attribute that sets initial variable values on scope before template rendering completes.
Purpose: Quick inline variable initialization useful for small demos, testing, or setting static defaults.
Example: Setting default starter chips on a board game table before players begin playing.
<div ng-app="" ng-init="quantity=3; cost=15"> <p>Total Price: {{ quantity * cost }}</p> </div>
Task: Use `ng-init` to set a user's name and age, then display them in a paragraph.
14. ng-model Directive
Meaning: Binds the value of HTML form controls (input, select, textarea) directly to application model variables.
Definition: Provides Two-Way Data Binding: changing input updates the model; changing model updates the input.
Purpose: Syncs user form entries with scope state instantly without writing event listener functions.
Example: Two mirrors facing each other — any movement in one instantly reflects in the other.
<div ng-app=""> <label>Enter City:</label> <input type="text" ng-model="city"> <p>Selected Destination: {{ city }}</p> </div>
Task: Create a form input with `ng-model` that lets users choose a background color dynamically.
15. ng-repeat Directive
Meaning: A directive that loops over a collection array and repeats the HTML element for every item.
Definition: Repeats a DOM element per item in an array using item in collection loop syntax.
Purpose: Renders dynamic lists, dropdown menus, table rows, and card grids from array datasets easily.
Example: A printing press stamping a page layout copy for every record in a database list.
<div ng-app="" ng-init="fruits=['Apple', 'Banana', 'Mango', 'Orange']"> <h3>Fruit Catalog:</h3> <ul> <li ng-repeat="x in fruits">{{ x }}</li> </ul> </div>
Task: Initialize an array of 3 student objects with `ng-init` and render them in a table using `ng-repeat`.
