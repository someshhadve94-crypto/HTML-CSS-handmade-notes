Component-Based Front-End Library

PART 1: REACT FOUNDATIONS & SETUP
1. Introduction & Environment Installation
Meaning: React is a popular JavaScript library created by Meta (Facebook) for building fast user interfaces.
Definition: An open-source, component-based front-end JS library used to construct Single Page Applications (SPAs).
Purpose: Simplifies complex UI development by splitting web pages into small, reusable building blocks.
Example: Assembling a toy house using individual interlocking LEGO bricks rather than molding one whole piece.
# Terminal commands to initialize React app with Vite npm create vite@latest my-react-app -- --template react cd my-react-app npm install npm run dev
Task: Install Node.js on your computer and generate a fresh React project using Vite.
2. Key React Features
Meaning: Core capabilities that make React fast, modular, and easy to maintain.
Definition: Key features include Virtual DOM, Declarative UI, One-Way Data Flow, and Component Architecture.
Purpose: Maximizes rendering performance and keeps application code structured as state updates over time.
Example: A smart blueprint that only updates the wall being repainted instead of rebuilding the entire house.
// Declarative UI: You describe WHAT the UI should look like based on state const App = () => { const isLoggedIn = true; return <h1>{isLoggedIn ? "Welcome Back!" : "Please Log In"}</h1>; };
Task: Explain how React's Virtual DOM improves browser performance compared to direct DOM updates.
3. Functional Components
Meaning: Modern and preferred way to write React components using simple JavaScript functions.
Definition: Plain JavaScript functions that receive props as inputs and return JSX elements to render on screen.
Purpose: Lightweight, easier to read/test, and fully empowered with State/Lifecycle features via React Hooks.
Example: A recipe card function that takes ingredient inputs and returns a formatted dish layout.
function Header() { return ( <header> <h1>My Application Header</h1> </header> ); } export default Header;
Task: Create a functional component named 'Footer' that returns a copyright paragraph.
4. Class Components
Meaning: The older ES6 class syntax used to write React components before Hooks were introduced in 2019.
Definition: ES6 classes extending React.Component that use a render() method to return JSX.
Purpose: Maintains legacy codebase compatibility, though modern React development uses Functional Components.
Example: An older mechanical typewriter — works reliably, but modern laptops (Functional components) are faster.
import React, { Component } from 'react'; class Welcome extends Component { render() { return <h1>Hello, {this.props.name}!</h1>; } } export default Welcome;
Task: Write a Class component that accepts a 'title' prop and renders it inside an h2 tag.
PART 2: JSX SYNTAX & PROPS
5. JSX: Syntax & Embedding Variables
Meaning: A syntax extension for JavaScript that lets you write HTML-like markup directly inside JS files.
Definition: Stands for JavaScript XML. JS expressions are embedded inside JSX markup using curly braces { expression }.
Purpose: Makes UI layout structure visual and allows dynamic data calculation inline.
Example: Filling in named blank variables inside a letter template directly where they appear.
const UserCard = () => { const username = "Alex"; const age = 22; return ( <div class="card"> <h3>User: {username}</h3> <p>Next Year Age: {age + 1}</p> </div> ); };
Task: Embed a math calculation, string variable, and ternary condition inside a JSX component.
6. Preprocessors & Babel in React
Meaning: Compiler tools that convert JSX and modern ES6+ code into plain JavaScript browsers can execute.
Definition: Babel is a JS transpiler that turns <div>Hello</div> into React.createElement('div', null, 'Hello').
Purpose: Guarantees cross-browser compatibility so developers can write modern JSX without browser rendering errors.
Example: A language translator converting slang directly into formal language for international readers.
// What you write in JSX: const element = <h1 className="title">Hello</h1>; // What Babel converts it to behind the scenes: const element = React.createElement('h1', { className: 'title' }, 'Hello');
Task: Look at the online Babel REPL compiler to see how JSX code translates to React.createElement.
7. Component Props (Properties)
Meaning: Inputs passed from parent components down to child components to configure them.
Definition: Read-only (immutable) parameters passed into a component using HTML-like attribute syntax.
Purpose: Makes components reusable with custom values and content across different parts of the application.
Example: Customizing custom order forms by supplying different names, dates, and amounts.
// Parent Component <Button label="Save Changes" color="green" /> <Button label="Delete Item" color="red" /> // Child Component const Button = ({ label, color }) => { return <button style={{ backgroundColor: color }}>{label}</button>; };
Task: Build a Product component that receives 'name', 'price', and 'inStock' boolean via props.
8. Pure vs Impure Functions in React
Meaning: Pure functions always return the same output for the same input without altering outside data.
Definition: React expects UI components to act like Pure Functions regarding their props (never modify their inputs).
Purpose: Prevents unpredictable UI bugs, side-effect mutations, and rendering inconsistencies.
Example: A math function add(2, 3) that always equals 5 without altering global room temperature.
// Pure Component (Safe): const Recipe = ({ cups }) => <p>Use {cups * 2} cups of water.</p>; // Impure Component (Unsafe - modifies external variable): let guestCount = 0; const BadComponent = () => { guestCount = guestCount + 1; // Mutating external variable! return <p>Guest #{guestCount}</p>; };
Task: Refactor an impure function component so it calculates values locally without mutating outer variables.
PART 3: STATE MANAGEMENT & REACT HOOKS
9. Component State & useState Hook
Meaning: Internal data memory managed inside a component that triggers a UI re-render when changed.
Definition: useState(initialValue) returns a state variable and a setter function: [state, setState].
Purpose: Handles dynamic data that changes based on user interactions like form typing, toggles, or counters.
Example: A digital scoreboard that automatically updates its displayed numbers when a button is pressed.
import { useState } from 'react'; const Counter = () => { const [count, setCount] = useState(0); return ( <div> <p>Clicks: {count}</p> <button onClick={() => setCount(count + 1)}>Increment</button> </div> ); };
Task: Create a toggle button component that switches text between "ON" and "OFF" using useState.
10. Side-Effects & useEffect Hook
Meaning: Handles operations that interact with the outside world beyond component rendering.
Definition: useEffect(callback, dependencyArray) runs side-effects like API data fetching, timers, or DOM subscriptions.
Purpose: Manages component lifecycle operations (mount, update, unmount) in functional components.
Example: Turning on a room's security alarm automatically whenever someone opens the main door.
import { useState, useEffect } from 'react'; const UserFetcher = () => { const [user, setUser] = useState(null); useEffect(() => { // Runs on component mount fetch('https://api.github.com/users/octocat') .then(res => res.json()) .then(data => setUser(data.name)); }, []); // Empty array = run ONCE on mount return <p>Loaded User: {user}</p>; };
Task: Use useEffect to update the browser tab document.title every time a counter state updates.
11. Cleanup Functions in useEffect
Meaning: A function returned inside useEffect that cleans up resources before the component unmounts.
Definition: Prevents memory leaks by clearing intervals, cancelling network requests, or removing event listeners.
Purpose: Cleans up background tasks when components disappear from screen to maintain app speed.
Example: Turning off the TV and unplugging the cable box before leaving a hotel room.
useEffect(() => { const timer = setInterval(() => console.log('Tick'), 1000); // Cleanup function executed on unmount return () => { clearInterval(timer); console.log('Timer Cleaned Up'); }; }, []);
Task: Build a clock component that starts a timer on mount and clears the interval on unmount.
12. Context API & Global State
Meaning: A built-in mechanism to share state across many component levels without prop drilling.
Definition: Uses createContext(), <Context.Provider>, and useContext() to broadcast data globally.
Purpose: Manages global data like user authentication, language preferences, or UI color themes.
Example: A radio broadcast tower sending news to all household radios tuned into the same frequency.
import { createContext, useContext } from 'react'; const ThemeContext = createContext('light'); const Display = () => { const theme = useContext(ThemeContext); // Read global context return <div className={`box ${theme}`}>Theme: {theme}</div>; }; const App = () => ( <ThemeContext.Provider value="dark"> <Display /> </ThemeContext.Provider> );
Task: Create a UserContext that passes logged-in username to a nested NavProfile component without prop drilling.
13. Component API & Reducers (useReducer)
Meaning: An alternative state management hook suited for complex state logic with multiple sub-actions.
Definition: const [state, dispatch] = useReducer(reducer, initialState) uses action objects to manage state transitions.
Purpose: Consolidates multiple state update rules into a single predictable reducer function.
Example: A bank teller executing specific transaction slips ("DEPOSIT", "WITHDRAW") against an account.
import { useReducer } from 'react'; function reducer(state, action) { switch (action.type) { case 'INCREMENT': return { count: state.count + 1 }; case 'DECREMENT': return { count: state.count - 1 }; default: return state; } } const Counter = () => { const [state, dispatch] = useReducer(reducer, { count: 0 }); return ( <button onClick={() => dispatch({ type: 'INCREMENT' })}> Count: {state.count} </button> ); };
Task: Write a reducer handling 'ADD_TODO' and 'DELETE_TODO' actions for a todo list array.
PART 4: EVENTS, STYLING & LIST RENDERING
14. Event Handling in React
Meaning: Capturing and responding to user actions like button clicks, form submissions, and typing.
Definition: Uses camelCase syntax (onClick, onChange, onSubmit) passing function references instead of strings.
Purpose: Triggers logic or updates component state in response to user inputs.
Example: Pressing a camera shutter button to trigger a photo capture event.
const Form = () => { const handleChange = (e) => { console.log("Typing:", e.target.value); }; return <input type="text" onChange={handleChange} placeholder="Type name..." />; };
Task: Create an input field that prints the entered text live inside a paragraph tag below it.
15. Styling in React (CSS, Modules & Bootstrap)
Meaning: Applying visual styles to components using inline objects, CSS modules, or CSS frameworks.
Definition: Inline styles use JS objects style={{ color: 'red' }}; class attributes are written as className="".
Purpose: Customizes component appearance while preventing global CSS class name collisions.
Example: Dressing individual actors in custom costumes tailored for their specific role.
// Inline Object Style const boxStyle = { backgroundColor: '#282c34', color: 'white', padding: '15px' }; const StyledCard = () => ( <div style={boxStyle} className="shadow-lg btn-group"> <p className="text-primary">Bootstrap & Inline Styled Card</p> </div> );
Task: Style a card component using a dynamic inline JS style object based on an 'isActive' boolean prop.
16. Rendering Lists & Table Structures
Meaning: Mapping over array datasets to dynamically generate repeating JSX components or table rows.
Definition: Uses the JavaScript map() method and requires a unique key prop on every mapped root item.
Purpose: Displays dynamic list collections and tabular data efficiently without duplicating markup.
Example: Printing a row for each item on a digital invoice statement.
const UserTable = ({ users }) => ( <table border="1"> <tbody> {users.map((user) => ( <tr key={user.id}> <td>{user.id}</td> <td>{user.name}</td> </tr> ))} </tbody> </table> );

PART 5: ROUTER, REDUX & E-COMMERCE PROJECT
17. React Router v6: Navigation & Routes
Meaning: Enables client-side page routing without refreshing the browser in Single Page Applications.
Definition: Library providing <BrowserRouter>, <Routes>, <Route>, and <Link> components.
Purpose: Switches view components based on the URL path seamlessly without page reloads.
Example: Switching tabs inside a desk binder — the binder frame stays still while pages swap.
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom'; const App = () => ( <BrowserRouter> <nav> <Link to="/">Home</Link> | <Link to="/about">About</Link> </nav> <Routes> <Route path="/" element={<Home />} /> <Route path="/about" element={<About />} /> </Routes> </BrowserRouter> );
Task: Set up React Router with 3 route paths: Home ("/"), Products ("/products"), and Contact ("/contact").
18. Query Params & URL Params in Router
Meaning: Extracting dynamic data parameters directly out of browser URL strings.
Definition: Uses hooks: useParams() for path variables (/product/:id) and useSearchParams() for query strings (?category=shoes).
Purpose: Loads specific detail pages (e.g. view item #42) or filters catalog lists based on shareable URL links.
Example: Reading a house number printed on a postal envelope to find the exact destination.
import { useParams, useSearchParams } from 'react-router-dom'; // URL: /product/101?discount=true const ProductDetail = () => { const { id } = useParams(); // Extracts 101 const [searchParams] = useSearchParams(); // Extracts query params return <div>Product ID: {id} (Discount: {searchParams.get('discount')})</div>; };
Task: Create a Route path "/user/:username" and display the extracted username on screen using useParams.
19. React Redux & Redux Toolkit
Meaning: A centralized global state management library for complex, enterprise-level React apps.
Definition: Uses a single global Store, Redux Slices (createSlice), useSelector to read state, and useDispatch to send actions.
Purpose: Provides a single source of truth for global data shared by dozens of independent components.
Example: A central bank ledger tracking everyone's balance — anyone can check or deposit through proper channels.
import { createSlice, configureStore } from '@reduxjs.toolkit'; import { useSelector, useDispatch } from 'react-redux'; // 1. Slice const cartSlice = createSlice({ name: 'cart', initialState: { items: [] }, reducers: { addToCart: (state, action) => { state.items.push(action.payload); } } }); // 2. Component dispatching action const AddBtn = () => { const dispatch = useDispatch(); return <button onClick={() => dispatch(cartSlice.actions.addToCart('Laptop'))}>Add</button>; };
Task: Create a simple Redux slice for a shopping cart counter with increment and decrement actions.
20. Project: E-Commerce Application Development
Meaning: A full capstone project integrating components, state, context/Redux, router, and product lists.
Definition: A real-world application featuring a product grid, search/filter inputs, dynamic shopping cart, routing, and checkout form.
Purpose: Combines all React fundamentals into a functional, production-style web application.
Example: Building an online store like Amazon or eBay.
// E-Commerce App Core Structure Skeleton const ECommerceApp = () => { const [cart, setCart] = useState([]); const [products] = useState([ { id: 1, name: "Phone", price: 600 }, { id: 2, name: "Headphones", price: 150 } ]); const addToCart = (product) => setCart([...cart, product]); return ( <div className="container"> <h1>Store (Cart Items: {cart.length})</h1> <div className="row"> {products.map(p => ( <div key={p.id} className="col-6 card p-3"> <h3>{p.name} - ${p.price}</h3> <button onClick={() => addToCart(p)}>Add to Cart</button> </div> ))} </div> </div> ); };
Task: Build a functional product list with an "Add to Cart" button that updates a top cart counter badge live.
