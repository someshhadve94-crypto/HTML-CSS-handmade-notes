High-Level Server-Side Programming Language

PART 1: PYTHON BASICS
1. Introduction to Python
Meaning: Python is a clean, readable, high-level programming language used for web development, automation, and data science.
Definition: An interpreted, object-oriented, dynamically typed programming language created by Guido van Rossum in 1991.
Purpose: Allows developers to build server-side web applications, automate tasks, write scripts, and process data with simple syntax.
Example: Writing plain English commands compared to complex machine instructions.
# Printing text in Python print("Hello, Python World!")
Task: Open a terminal and check your installed Python version using `python --version`.
2. Installation & Downloads
Meaning: Setting up the Python interpreter environment on your operating system (Windows, Mac, Linux).
Definition: Downloading official setup binaries from python.org and adding Python to the system environment PATH variable.
Purpose: Equips your computer to compile and execute Python script files (.py).
Example: Installing an engine inside a vehicle frame so it can run.
# Run Python interactive shell in terminal python >>> print(10 + 20) 30 >>> exit()
Task: Download Python 3.x from python.org and verify PATH environment checkbox during setup.
3. Basic Syntax & Editors
Meaning: The foundational rule system of writing Python code using text editors or IDEs.
Definition: Python syntax uses clean commands executed line-by-line using editors like VS Code, PyCharm, or IDLE.
Purpose: Keeps code clean, readable, and consistent across software projects.
Example: Writing clean lined notebook entries instead of cluttered random notes.
# Basic Python file execution x = 5 y = 10 print(x + y)

4. Comments in Python
Meaning: Developer notes inside Python code ignored completely by the interpreter.
Definition: Single-line comments start with #; multi-line docstrings use triple quotes """ """.
Purpose: Explains complex logic, documents functions, and temporarily disables code lines during debugging.
Example: Sticky notes placed on code pages for team members.
# This is a single-line comment """ This is a multi-line comment string in Python """ print("Comments are ignored!")

5. Indentation in Python
Meaning: Using whitespace margins at the beginning of code lines to define code blocks.
Definition: Python replaces curly braces { } with consistent indentation (usually 4 spaces) to mark function/loop/if scope.
Purpose: Enforces structured, clean visual code readability automatically.
Example: Writing indented bullet lists under chapter headings in an outline.
if True: print("Indented block (4 spaces)") # Correct # print("Unindented block") -> Causes IndentationError

PART 2: VARIABLES, TYPES & CASTING
6. Python Variables
Meaning: Reserved memory locations used to store data values inside a program.
Definition: Created the moment a value is assigned using the assignment operator = (no keyword needed).
Purpose: Holds dynamic data for processing, calculation, and manipulation.
Example: Labeling a storage box with a name tag "User_Age" to hold a number.
age = 25 # Integer variable name = "Alex" # String variable price = 99.99 # Float variable print(name, age)

7. Data Types in Python
Meaning: Categorization of data values determining what operations can be performed on them.
Definition: Built-in types: str, int, float, bool, list, tuple, dict, set.
Purpose: Instructs Python how to store and handle data structures in memory.
Example: Sorting items into text files, numeric receipts, and true/false checklists.
a = "Hello" # str b = 10 # int c = 10.5 # float d = True # bool print(type(a), type(b))

8. Variable Scope (Local vs Global)
Meaning: The accessibility region of a variable inside Python code.
Definition: Global variables exist outside functions; local variables exist inside functions. Use global keyword to modify global variables locally.
Purpose: Protects variables from unexpected modifications across different function scopes.
Example: Public town noticeboard (Global) vs private personal diary (Local).
x = "Global" # Global Variable function_demo(): y = "Local" # Local Variable print(y) print(x)

9. Type Casting (to String, Integer, Float)
Meaning: Converting a variable from one data type to another explicitly.
Definition: Uses constructor functions str(), int(), and float() to convert data types.
Purpose: Converts string user inputs into numbers for mathematical calculations.
Example: Converting text "50" on a paper form into a numeric math calculation value.
num_str = "100" num_int = int(num_str) # Converts to int: 100 num_float = float(num_str)# Converts to float: 100.0 text = str(num_int) # Converts back to str: "100"

PART 3: PYTHON OPERATORS
10. Arithmetic Operators
Meaning: Operators used to execute standard mathematical operations on numbers.
Definition: Includes +, -, *, /, % (Modulus), ** (Exponentiation), // (Floor Division).
Purpose: Executes math calculations, exponent powers, and integer division.
Example: Pocket calculator performing addition, division, and percentage calculations.
a = 15 b = 4 print(a + b) # 19 print(a // b) # 3 (Floor division - drops decimal) print(a ** b) # 50625 (15 to power 4)

11. Assignment Operators
Meaning: Operators used to assign or update values stored in variables.
Definition: Includes =, +=, -=, *=, /=, %=.
Purpose: Shortens code when updating existing variable values in place.
Example: Updating score balances on a digital arcade machine.
score = 10 score += 5 # score = score + 5 (15) score *= 2 # score = score * 2 (30) print(score)

12. Logical & Comparison Operators
Meaning: Comparison operators evaluate relationships; Logical operators combine multiple condition checks.
Definition: Comparisons: ==, !=, >, <, >=, <=. Logical: and, or, not.
Purpose: Evaluates conditions to drive control flow decisions in programs.
Example: "Allow entry if age >= 18 AND ticket is True."
age = 20 has_id = True print(age >= 18 and has_id) # True print(age < 18 or has_id) # True print(not has_id) # False

PART 4: CONDITIONAL STATEMENTS & LOOPS
13. IF, Elif, Else Conditions
Meaning: Decision-making structures that execute specific code blocks based on condition evaluation.
Definition: Uses keywords if, elif (else if), and else with indented code blocks.
Purpose: Directs execution path based on variable values and conditions.
Example: Traffic signal logic: If Red = Stop, Elif Yellow = Slow, Else = Go.
marks = 85 if marks >= 90: print("Grade A") elif marks >= 75: print("Grade B") else: print("Grade C")
Task: Write an IF-Elif-Else script that checks if a number is positive, negative, or zero.
14. Nested IF Statements
Meaning: An IF condition placed inside another IF condition block.
Definition: Inner indented IF blocks evaluated only after outer IF condition passes True.
Purpose: Handles multi-tiered conditional checks (e.g. login security steps).
Example: Checking if user has account first, then checking if password is correct.
age = 20 nationality = "Indian" if age >= 18: if nationality == "Indian": print("Eligible to Vote in India") else: print("Not an Indian Citizen")
Task: Write a nested IF checking if a number is even, and if so, whether it is greater than 100.
15. While Loop
Meaning: A loop that repeats a code block continuously as long as a condition stays True.
Definition: Uses while condition: and requires manual variable incrementing inside to prevent infinite loops.
Purpose: Used when total iteration count is unknown beforehand.
Example: Running a water pump continuously until the storage tank is full.
count = 1 while count <= 5: print("Count:", count) count += 1 # Increment to stop loop

16. For Loop & range() Function
Meaning: A loop that iterates over a sequence (list, tuple, string) or a numeric range.
Definition: Uses for item in sequence: combined with range(start, stop, step) function.
Purpose: Iterates through data collections or repeats code a fixed number of times.
Example: Reading every book page sequentially from page 1 to 100.
# Iterating range 1 to 5 for i in range(1, 6): print("Step:", i) # Iterating a list fruits = ["Apple", "Banana", "Mango"] for fruit in fruits: print(fruit)

PART 7: OBJECT-ORIENTED PROGRAMMING (OOPS)
23. Classes & Objects in Python
Meaning: Object-Oriented Programming model where Classes act as blueprints and Objects act as real instances.
Definition: Defined using class ClassName: and initialized with constructor method __init__(self).
Purpose: Models real-world entities combining attributes (data) and methods (behavior) together.
Example: Architect house blueprint (Class) vs actual physical house built on a lot (Object).
class Car: def __init__(self, brand, color): self.brand = brand # Property self.color = color def drive(self): # Method print(f"{self.color} {self.brand} is driving!") # Creating Object Instance my_car = Car("Toyota", "Red") my_car.drive()

24. Inheritance in Python
Meaning: Mechanism where a child class inherits attributes and methods from a parent class.
Definition: Class syntax written as class ChildClass(ParentClass):, using super() to access parent methods.
Purpose: Promotes code reuse and creates hierarchical class relationships.
Example: Child inheriting eye color, height, and last name from parents.
class Animal: def speak(self): print("Animal makes sound") class Dog(Animal): # Dog inherits from Animal def bark(self): print("Dog barks!") d = Dog() d.speak() # Inherited method d.bark()

25. Python Iterators
Meaning: An object that contains a countable number of values and can be iterated through one by one.
Definition: Implements methods __iter__() and __next__() to step through elements sequentially.
Purpose: Memory-efficient iteration over data collections without loading all items into memory at once.
Example: Turning pages in a physical book one single page at a time.
fruits = ("Apple", "Banana", "Mango") my_iter = iter(fruits) # Create iterator print(next(my_iter)) # Apple print(next(my_iter)) # Banana

26. Polymorphism in Python
Meaning: The ability of different classes to execute methods sharing the same name in unique ways.
Definition: Methods in different classes with identical function signatures returning custom behaviors per class instance.
Purpose: Provides unified function interfaces for different underlying class object types.
Example: Pressing "Play" button — plays music on audio player, plays video on movie player.
class Dog: def sound(self): return "Woof!" class Cat: def sound(self): return "Meow!" # Polymorphic Execution for pet in [Dog(), Cat()]: print(pet.sound())
